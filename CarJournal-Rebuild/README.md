# Журнал машин - новая тестовая версия

Исходный проект был недоступен, поэтому это **новая реализация по скриншотам и структуре APK**, а не декомпиляция исходников один в один.

## Что работает в коде

- Новый отдельный Android-пакет `com.carjournal.rebuild` - тестовая сборка не заменяет `com.carjournal.app`.
- Список машин и поиск по госномеру/марке/модели.
- По умолчанию сверху недавно добавленные машины.
- Новая машина + первый ремонт за одно сохранение (Room transaction). Первый ремонт можно отключить переключателем.
- Отдельное добавление/редактирование ремонта.
- Выбор нескольких фотографий из галереи или съёмка камерой - до 10 на ремонт.
- Удаление выбранных фотографий до сохранения; удаление уже сохранённых фотографий при редактировании ремонта.
- Добавление/замена/удаление фотографии машины.
- Суммы ремонтов по валютам KGS и RUB отдельно, количество машин и ремонтов.
- Удаление машины только из её карточки с подтверждением.
- Подстройка под системную клавиатуру `adjustResize` и `imePadding`, прокрутка длинных форм.

## ВАЖНО про данные

Это **новое приложение с отдельной базой** `car_journal_rebuild.db`. Старые машины не импортируются автоматически. Не удаляйте старое приложение с телефона. Старый APK может содержать зашифрованную базу; тут обычная Room/SQLite, **без SQLCipher, PIN-кода и облака**. Не используйте эту сборку для важных данных, пока не завершено тестирование и резервное копирование.

## Открыть в Android Studio

1. Распакуйте ZIP в папку, например `C:\Projects\CarJournal-Rebuild`.
2. В Android Studio выберите **File > Open** и укажите папку с `settings.gradle.kts`.
3. Дождитесь Gradle Sync. Нужны JDK 17 и Android SDK 36 (Android Studio предложит установить недостающие компоненты). Интернет понадобится для загрузки зависимостей.
4. Выберите эмулятор или подключённый телефон, нажмите зелёную кнопку **Run**.
5. Проверьте добавление машины, её первого ремонта, несколько фото, удаление фото и редактирование ремонта.

**Ограничение архива:** в этой среде недоступна загрузка бинарного Gradle Wrapper JAR. В папке есть `gradle/wrapper/gradle-wrapper.properties`, но **нет** `gradle-wrapper.jar` / `gradlew`. Для первого запуска можно настроить Android Studio на локальную установку Gradle 8.13, а затем в терминале проекта выполнить `gradle wrapper --gradle-version 8.13`, чтобы создать полноценную обёртку. В среде Android Studio, где Gradle локально не установлен, сначала создайте пустой проект с Gradle Wrapper и перенесите в него эти файлы; или установите Gradle 8.13.

## Технические замечания

- Оригиналы фотографий в галерее не удаляются: приложение сохраняет собственные копии в `filesDir/journal_photos`. При удалении удаляется только внутренняя копия.
- В тестовой версии фотографии не сжимаются: при большом количестве фото нужно добавить ресайз/компрессию.
- Для сумм RUB и KGS конвертация по валютному курсу намеренно не производится.
- Это стартовая реализация **без проверки сборки на Android SDK** в текущей среде. Если Android Studio покажет ошибки Sync/Compile, отправьте вывод, и мы поправим конкретную проблему.
- Нет аккаунтов/облачной синхронизации, статистики по годам, PIN-кода/сброса PIN и импорта старой базы. Эти этапы - следующие.

## Сборка APK без Android Studio (GitHub Actions)

В проект добавлен `.github/workflows/android-apk.yml`. Workflow устанавливает JDK 17,
Android SDK 36 и Gradle 8.13 на GitHub-hosted runner, собирает `:app:assembleDebug`
и публикует APK как артефакт `CarJournal-debug-apk`.

1. Создайте **пустой** репозиторий GitHub (без README и .gitignore).
2. Распакуйте этот ZIP. Загрузите **содержимое папки** `CarJournal-Rebuild`,
   включая скрытую папку `.github`, в корень репозитория.
3. В `Actions` откройте `Build Android APK`. Если требуется, включите workflows
   и нажмите `Run workflow`; также workflow запустится при push в ветку `main`.
4. После успешной сборки загрузите артефакт `CarJournal-debug-apk`, распакуйте его
   и установите `app-debug.apk` на Android-устройство.

**Важно:** код пока не был скомпилирован в этой среде. Возможны ошибки сборки,
которые будут видны в логе `Build debug APK`. Тестовый пакет `com.carjournal.rebuild`
не заменяет старую установленную версию; не переносит её данные автоматически.
